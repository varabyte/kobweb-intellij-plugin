Reports @Page route overrides and @file:PackageMapping values that don't change the route Kobweb would generate anyway, or that could be written more simply.

Kobweb recommends letting it generate routes from file and package names where possible, which makes it easier to tell where a URL comes from. 


// pages/blog/Post.kt
@Page("post")         // Redundant, as the route is "/blog/post" either way
@Page("/blog/post")   // Redundant
@Page("{post}")       // Can be simplified to "{}"

// pages/ourTeam/PackageMapping.kt
@file:PackageMapping("our-team")  // Redundant, as Kobweb already turns "ourTeam" into "our-team"
