Reports @Layout annotations that Kobweb will reject when building your site.

A layout path must point at a function annotated with @Layout. Paths that start with a period are relative to your project's group.

Pages and default layouts (i.e. @file:Layout) must specify a path. (Layouts themselves can leave it out, as in that case it simply means they don't have a parent layout.) 


// OK
@Page
@Layout(".components.layouts.PageLayout")
@Composable
fun HomePage() { }

// Not OK (no such layout)
@Page
@Layout(".components.layouts.MissingLayout")
@Composable
fun HomePage() { }

// Not OK (pages must specify a path)
@Page
@Layout
@Composable
fun HomePage() { }
