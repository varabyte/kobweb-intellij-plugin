Reports routes that don't lead to any page or public resource, which are usually typos or links to pages that were moved or deleted.

This inspection applies to parameters that are annotated by Kobweb with @RoutePath (excluding ones where mustExist is set to false), such as the path parameter in the Link composable. 


// pages/blog/Post.kt is served at "/blog/post"
Link("/blog/post")    // OK
Link("/blog/pots")    // Doesn't correspond to any known page or public resource
Link("/blog/$slug")   // OK, as the value of "slug" isn't known until runtime
// resources/public/docs/resume.pdf is served at "/docs/resume.pdf"
Link("/docs/resume.pdf") // OK
Link("/dcos/resume.pdf") // Unknown resource
