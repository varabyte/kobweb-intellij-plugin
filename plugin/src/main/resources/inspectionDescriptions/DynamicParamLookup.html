Reports lookups of a route's dynamic segment that could use dynamicParams.getValue instead.

Kobweb always fills in every dynamic segment, so reading one doesn't need a null check or a default value. Reading it from dynamicParams rather than params also gets its key checked against the route, so a typo or a later rename of the segment gets reported instead of failing at runtime. 


@Page("{user}/posts/{post}")
@Composable
fun PostPage(ctx: PageContext) {
    ctx.route.params["post"]!!                 // Can be replaced with dynamicParams.getValue
    ctx.route.dynamicParams["post"] ?: ""      // Can be replaced with dynamicParams.getValue
    ctx.route.dynamicParams.getValue("post")   // OK
}
