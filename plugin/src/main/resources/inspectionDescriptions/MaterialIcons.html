Reports Google's Material Icons icon set (mdi()) in a build script's icons { ... } block. Google has deprecated Material Icons in favor of Material Symbols (ms()), which has more icons and gets updates.

Icon names and styles differ between the two sets, so switching means updating the icons you use by hand. 


kobweb {
    app {
        icons {
            mdi() // Consider ms() instead
        }
    }
}
