Reports @Layout annotations on pages that point at the default layout the page would use anyway (i.e. the one set by the closest @file:Layout annotation in its package).

Removing the annotation doesn't change the page. However, you may prefer to keep it, so that the page keeps its layout even if the default changes later, in which case you can turn this inspection off. 


// pages/blog/DefaultLayout.kt
@file:Layout(".components.layouts.BlogLayout")

// pages/blog/FirstPost.kt
@Page
@Layout(".components.layouts.BlogLayout") // Redundant
@Composable
fun FirstPost() { }
