Reports routes passed to parameters that don't accept them as written, according to the parameter's @RoutePath(type = ...), which is one of:
  • URL (the default): any URL, including ones to other sites, e.g. "/blog/post" or "https://example.com". Used by Link and Router.navigateTo, for example.
  • PATH_QUERY_AND_FRAGMENT: a path within the site, optionally followed by query parameters and a fragment, e.g. "/blog/post?sort=new#comments", but not a full URL. Used by Router.tryRoutingTo, for example.
  • PATH_ONLY: just a path within the site, e.g. "/blog/post", without query parameters or a fragment.

// OK
router.tryRoutingTo("/blog/post?sort=new")
// Not OK: not a path within the site.
router.tryRoutingTo("https://example.com/blog")

// User code can use the annotation as well
fun Breadcrumb(@RoutePath(RoutePathType.PATH_ONLY) path: String)
// OK
Breadcrumb("/blog/post")
// Not OK: accepts paths only, no fragments or query parameters
Breadcrumb("/blog/post#comments")
