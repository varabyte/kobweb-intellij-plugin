Reports icons imported from a prebuilt Silk icon artifact (e.g. silk-icons-fa) when the module generates the same icon set itself, with an icons { ... } block in its build script.

Both have the same icons with the same names, so the quick fix just changes the import.

A module usually only has both while migrating from the artifact to generated icons. Once nothing imports from the artifact anymore, remove its dependency from the build script. 


// build.gradle.kts
kobweb {
    app {
        icons {
            fa()
        }
    }
}

// Before
import com.varabyte.kobweb.silk.components.icons.fa.FaHouse

// After
import com.example.components.icons.fa.FaHouse

Running Code | Code Cleanup fixes every such import in the project at once.
