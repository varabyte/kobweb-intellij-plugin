Reports keys into dynamicParams that aren't the name of one of the route's dynamic segments, which can only ever be null. Reading one with getValue always throws, so that's reported as an error.

Keys into params aren't checked, as it can hold query parameters too. 


@Page("{user}/posts/{post}")
@Composable
fun PostPage(ctx: PageContext) {
    ctx.route.dynamicParams["post"]           // OK
    ctx.route.dynamicParams["pots"]           // Warning: This route has no dynamic segment named "pots"
    ctx.route.dynamicParams.getValue("pots")  // Error: This always throws
}
