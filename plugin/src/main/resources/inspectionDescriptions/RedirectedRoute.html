Reports routes that a redirect in the site's .kobweb/conf.yaml sends somewhere else.

Redirects are meant for links from outside your site, such as bookmarks and search results, so links in your own code can go straight to the new route. Any references to old links found inside your code are be assumed to be stale, e.g. something you missed when doing a site cleanup. 


# .kobweb/conf.yaml
server:
  redirects:
    - from: "/old-page"
      to: "/new-page"

// In code
Link("/old-page")   // Redirected to "/new-page"
Link("/new-page")   // OK
