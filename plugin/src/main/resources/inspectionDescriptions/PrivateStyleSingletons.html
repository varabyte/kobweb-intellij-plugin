Reports Kobweb style-type properties (like CssStyle and Keyframes) that should be declared as public (so the generated Kobweb code can find and register them). These value are allowed to be private but only if annotated with a proper `@Suppress` annotation or named with a leading underscore. 

// OK
val MyStyle = CssStyle { }

// Not OK
private val MyStyle = CssStyle { }

// Suppression is OK
@Suppress("PRIVATE_CSS_STYLE")
private val MyStyle = CssStyle { }

// Leading underscore is OK
private val _MyStyle = CssStyle { }
