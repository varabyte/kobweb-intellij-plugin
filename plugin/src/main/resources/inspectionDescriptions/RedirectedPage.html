Reports pages that are never shown, because a redirect in the site's .kobweb/conf.yaml sends their route somewhere else. This usually means that the page was replaced, and either the page or the redirect was left behind. 

# .kobweb/conf.yaml
server:
  redirects:
    - from: "/old-page"
      to: "/new-page"

// pages/OldPage.kt is served at "/old-page", but visitors are always sent to "/new-page" instead
@Page
@Composable
fun OldPage() { ... }

To fix this, decide which one was left behind:

  • If the page was replaced by the one the redirect leads to, delete it (or move anything still needed into the new page). Keep the redirect, as links from outside the site, such as bookmarks and search results, may still use the old route.
  • If the page is meant to be shown, remove or narrow the redirect in .kobweb/conf.yaml. The "Go to redirect" quick fix opens it.
