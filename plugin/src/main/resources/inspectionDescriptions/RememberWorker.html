Reports the use of remember when rememberWorker should be used instead.

The rememberWorker method ensures that a worker will be terminated when the current composable scope is exited, e.g., if the user navigates away from the current page. 


// Not OK. Can leave a worker running
// forever in the background.
val worker = remember {
    SomeWorker()
}

// Recommended!
val worker = rememberWorker {
    SomeWorker()
}
