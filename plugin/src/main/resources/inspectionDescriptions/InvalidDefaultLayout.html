Reports default layouts (i.e. @file:Layout) that Kobweb rejects when building your site, i.e. ones outside the pages package.

A default layout applies to the pages in its package (and subpackages), so it must live somewhere under the pages package. 


// pages/blog/BlogLayout.kt (OK)
@file:Layout(".components.layouts.BlogLayout")
package com.example.pages.blog

// components/Layouts.kt (Not OK)
@file:Layout(".components.layouts.PageLayout")
package com.example.components
