Reports @Page route overrides and @file:PackageMapping values that Kobweb rejects, or that it accepts but are almost certainly mistakes.

Kobweb would skip generating pages for:

  • route overrides which put an inferred ({}), catch-all ({...}), or optional ({?}) dynamic segment anywhere but at the end
  • pages that live outside the pages package (unless they specify an absolute path)
And it would fail the build for routes that start with api, which it reserves to avoid conflicts with backend API routes.

This also reports malformed dynamic segments, empty segments, and characters that can't be part of a route. 


// pages/users/Posts.kt
@Page("{}/posts")  // Inferred segment isn't at the end, so Kobweb skips this page
@Page("{post")     // Malformed dynamic segment
@Page("a//b")      // Empty segment
