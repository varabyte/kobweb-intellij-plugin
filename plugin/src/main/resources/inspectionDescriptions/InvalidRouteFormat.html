Reports routes that aren't in the format expected where they're used.

Some places that take a route only accept part of a URL. For example, Router.tryRoutingTo only accepts a path within the site (optionally followed by query parameters and a fragment), not a full URL. Similarly, ctx.route.path only ever holds a path, so comparing it against a route with query parameters is never true. 


// OK
router.tryRoutingTo("/blog/post?sort=new")
// Not OK: not a path within the site
router.tryRoutingTo("https://example.com/blog")

// Not OK: ctx.route.path never includes query parameters, so this is never true
if (ctx.route.path == "/blog/post?sort=new") { ... }
