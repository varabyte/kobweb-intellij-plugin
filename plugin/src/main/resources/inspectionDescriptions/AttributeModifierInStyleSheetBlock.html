Reports the use of attribute modifiers (like Modifier.id("example")) inside CssStyle definitions. These will cause runtime exceptions if left in place, so you should consider moving them out of the CssStyle entirely or into the `extraModifier` argument that `CssStyle` blocks can take. 

// Not OK
val MyStyle = CssStyle {
    base {
        Modifier
            .color(Colors.Magenta)
            .id("my-id") // <-- Attribute modifier!
    }
}

MyStyle.toModifier()

// OK #1
val MyStyle = CssStyle(extraModifier = { Modifier.id("my-id") }) {
    base {
        Modifier
            .color(Colors.Magenta)
    }
}

MyStyle.toModifier()

// OK #2
val MyStyle = CssStyle {
    base {
        Modifier.color(Colors.Magenta)
    }
}

MyStyle.toModifier().id("my-id")
