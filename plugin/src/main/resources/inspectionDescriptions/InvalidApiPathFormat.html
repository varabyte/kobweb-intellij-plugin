Reports API paths that aren't in the format expected by what they're used with.

API paths, such as those passed to window.api.get, are relative to /api/, so they can't be full URLs. API stream paths, such as those passed to ApiStream, must match a stream's path exactly, so they can't have query parameters or a fragment either. 


// OK
window.api.get("users?id=5")
ApiStream("chat")
// Not OK: not a path relative to "/api/"
window.api.get("https://example.com/api/users")
// Not OK: stream paths can't have query parameters
ApiStream("chat?room=general")
