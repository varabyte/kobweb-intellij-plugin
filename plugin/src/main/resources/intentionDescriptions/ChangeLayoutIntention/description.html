This action lets you change a page's layout, by choosing from a list of all the layouts available to your project.

It's available on a @Layout annotation's path, which it replaces with your choice, as well as on pages that use a default layout (set by a @file:Layout annotation). 


// Before
@Page
@Layout(".components.layouts.PageLayout")
@Composable
fun BlogPage() { }

// After (choosing BlogLayout)
@Page
@Layout(".components.layouts.BlogLayout")
@Composable
fun BlogPage() { }
