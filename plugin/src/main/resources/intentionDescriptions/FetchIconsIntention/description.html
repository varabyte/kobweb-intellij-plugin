This action fetches the data for the icon sets in a module's icons { ... } block, by running the kobwebFetchIcons Gradle task, and then generates the icons' Kotlin bindings. 

kobweb {
    app {
        icons {
            fa()
        }
    }
}

Check in the files the task writes to kobweb-store/icons.

Icons are only fetched when you ask for them, so builds don't need network access. Fetch them again after changing an icon set's version (e.g. fa { version.set("7.+") }), or to update a version range like 7.+ to the latest release.
